# Viewer

Mode: Operate

Audience: benchmark operators deciding whether WARP helps for the tested destinations.
Job: import one local Schema v1 result, verify whether its evidence is comparable, then inspect destination- and metric-level outcomes.
Primary action: open a result file and follow its clearance state into route-level evidence.
Proof: paired latency, loss, RTT variation, throughput, loaded latency, and interval timelines derived from compatible measurements only.
Constraints: one offline HTML file; no uploads; safe untrusted JSON handling; desktop and mobile accessibility; missing values never become zero; false certainty is the principal failure mode.

## Direction contract

THESIS: The viewer is a route dispatch board that clears evidence before it clears a route. It refuses the category-default dashboard of interchangeable metric cards and never lets a large winner label outrun comparison validity.

OWN-WORLD: A neutral dispatch-paper field carries clipped route strips, graphite rules, carbon-copy Direct blue, WARP orange, and safety-ink status marks. Condensed dispatch headings contrast with highly legible tabular data. Controls behave like tabs, stamps, and clipped selectors rather than floating pills. The system remains presentation-neutral in light and dark ambient contexts by using a low-glare light field with strong ink contrast.

STORY: The operator imports a local file, sees whether the run is cleared for comparison, and then scans each destination strip for aligned Direct/WARP measurements. Warnings stay attached to affected evidence. Selecting a strip opens its measurements and transfer timeline without losing the fleet-wide context.

FIRST VIEWPORT: A compact masthead and local-file control sit above one broad clearance sheet. The left two-thirds state whether comparison is permitted, with a visible validity stamp and counts of paired tests and destinations. The right third records run identity, profile, phases, and privacy. The first destination strips begin before the fold on desktop; mobile stacks the clearance record, then places each paired route on one readable strip.
